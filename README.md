# 判讀法庭：像素裁決

供香港小一至小六學生在言語治療師陪同下使用的繁體中文閱讀遊戲原型。

玩家扮演法官，閱讀控辯雙方陳詞，完成五項證據挑戰，然後選擇裁決、處理方法並撰寫判詞。原型包括：

- 事實、推論、語意、雙文整合及證據判讀題目
- 「一般提示 → 具體提示 → 顯示答案」動態評估流程
- 選取文字後以香港中文語音朗讀
- 24 名可重用成人像素角色與法庭動畫
- 每個年級 30 宗（共 180 宗）按篇幅、事件層次及詞彙難度編排的案件；開場直接「選年級 → 選案件 → 開始審訊」
- 原型參考公平判決：結尾比較學生選擇的罪責／處分與案件的參考判決，顯示接近度及 A–D 近似級別，不使用 EXP
- 以答對率、作答時間、提示依賴、重看陳詞及改選次數計算的本案表現摘要，方便 SLP 會談時檢視
- 24 名可重用成人像素角色、法庭場景及宣判後的反應動畫

案件與參考裁決由本地內容庫提供；`app/expanded-case-bank.ts` 以 30 個情境種子建立六個語言級別，每宗均含雙方陳詞、事實／推論／語意／整合／證據五題、一般及具體提示。正式版接駁 DeepSeek 前，應保留預先準備並經臨床審閱的安全後備案件。

## 開發

```bash
npm install
npm run dev
npm test
npm run lint
```

完成判決的本案 JSON 會暫存於瀏覽器的 `localStorage`，方便會談後匯出；原型尚未連接學生資料庫。
