# 判讀法庭：像素裁決

供香港小一至小六學生在言語治療師陪同下使用的繁體中文閱讀遊戲原型。

玩家扮演法官，閱讀控辯雙方陳詞，完成五項證據挑戰，然後選擇裁決、處理方法並撰寫判詞。原型包括：

- 事實、推論、語意、雙文整合及證據判讀題目
- 「一般提示 → 具體提示 → 顯示答案」動態評估流程
- 選取文字後以香港中文語音朗讀
- 24 名可重用成人像素角色與法庭動畫
- 20 宗按年級、篇幅、事件層次及詞彙難度編排的案件
- AI 參考裁決原型：按罪責與處分接近程度計算判決 EXP
- 可儲存的學生法官性別、外觀及法袍組合
- 六級法官 EXP 系統，逐級開放更高級別案件與法袍
- 本地學生進度與行為紀錄
- 根據表現更新的啟發式難度與題型選擇

目前的案件與 AI 參考裁決由原型內容庫提供；正式版接駁 DeepSeek 前，應保留預先準備並經臨床審閱的安全後備案件。

## 開發

```bash
npm install
npm run dev
npm test
npm run lint
```

資料只會儲存在瀏覽器的 `localStorage`；原型尚未連接學生資料庫。
